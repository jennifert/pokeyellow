# Pokémon Soul Yellow Guide

A complete walkthrough and reference guide for Pokémon Soul Yellow.

## About This Guide

This guide documents the story progression, locations, Pokémon,
trainers, items, events, and mechanics found in Pokémon Soul Yellow.

It is written specifically for Soul Yellow rather than being a modified
Pokémon Yellow walkthrough.

## Original Walkthrough Reference and Attribution

This guide was created with reference to the original
Pokémon Red/Blue/Yellow FAQ/Walkthru by Lando_Kashmir.

The original guide is preserved separately as a historical reference
for Pokémon Yellow's original progression and content.

Soul Yellow changes and additions are documented independently in this
guide.
